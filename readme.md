# GULP заготовка  

## Струткура папок  

Если отсутствует "/build" значит сборка еще не запускалась.  
'src' - содержит все исходники.  



## Установленные пакеты  

'npm init'  
'npm i gulp -D'  
'npm i gulp-sass sass -D' [gulp-sass](https://www.npmjs.com/package/gulp-sass)  
'npm i browser-sync -D' [browser-sync](https://www.npmjs.com/package/browser-sync)  
'npm i gulp-file-include' [gulp-file-include](https://www.npmjs.com/package/gulp-file-include)  
'npm i gulp-sourcemaps' [gulp-sourcemaps](https://www.npmjs.com/package/gulp-sourcemaps)  

#### Архив  

'npm i gulp-include -D' [gulp-include, слабо есть gulp-file-include](https://www.npmjs.com/package/gulp-include)  
'npm i gulp-clean -D' [gulp-clean, сомнительно](https://www.npmjs.com/package/gulp-clean)  
'npm i gulp-ttf2woff2 -D' [gulp-ttf2woff2, ничего не конвертирует](https://www.npmjs.com/package/gulp-ttf2woff2)  


## Запуск  

gulp // запуск сборки с последующем вотчером  
gulp watcher // вотчер
