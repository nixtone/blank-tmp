# GULP заготовка  

## Струткура папок  

Если отсутствует "/build" значит сборка еще не запускалась.  
'src' - содержит все исходники.  



## Установленные пакеты  

'npm init'  
'npm i gulp -D'  
'npm i gulp-sass sass -D' [gulp-sass](https://www.npmjs.com/package/gulp-sass)  
'npm i gulp-include -D' [gulp-include](https://www.npmjs.com/package/gulp-include)  
'npm i gulp-clean -D' [gulp-clean](https://www.npmjs.com/package/gulp-clean)  
'npm i gulp-ttf2woff2 -D' [gulp-ttf2woff2](https://www.npmjs.com/package/gulp-ttf2woff2)  
'npm i browser-sync -D' [browser-sync](https://www.npmjs.com/package/browser-sync)
